# Test Case Preparation

## Step 1 — Requirement Analysis

The following features were identified for testing:

- Login
- Task Creation
- Task Update
- Task Delete
- Search Functionality
- Filter Functionality
- Dashboard Statistics

---

## Step 2 — Identify Testing Types

The following testing types were selected:

- Functional Testing
- Negative Testing
- UI Testing
- Integration Testing
- Validation Testing
- Performance Testing

---

## Step 3 — Prepare Test Cases

15 test cases were created from TC-001 to TC-015.

Each test case contains:
- Test Case ID
- Test Case Name
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Status

---

## Step 4 — Execute Test Cases

Test cases were executed using:

Frontend:
- http://localhost:5173

Backend API Docs:
- http://127.0.0.1:8000/docs

---

## Step 5 — Record Results

After execution:
- Pass/Fail status was updated
- Defects were logged
- Failed test cases were re-tested after fixes

---

- FastAPI Swagger Docs
